# Sport Management System

## Giới thiệu

Sport Management System là hệ thống quản lý và vận hành sân thể thao, hỗ trợ chủ sân và khách hàng trong việc đặt sân, quản lý lịch đặt, thanh toán và theo dõi hoạt động của sân.

## Mục tiêu

- Quản lý sân thể thao
- Quản lý người dùng
- Đặt sân trực tuyến
- Quản lý lịch đặt
- Thanh toán
- Thống kê doanh thu

## Công nghệ sử dụng

### Frontend

### Backend
